# Article 4 direction boundary tracing

Pages for hand-tracing the boundaries of Article 4 directions (UK planning orders that
remove permitted development rights) from the councils' own signed direction documents.

Each borough folder holds the council's public direction document and map sheets as
images, and a page (`index.html`) that shows them beside a live map with a simple
tracing tool. `tool/` is the shared tracing app. `review-N.html` pages are automated
check reports on submitted tracings.
